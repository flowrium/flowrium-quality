# 需求定义

## 环节目标

准确理解和表达用户需求，建立可追溯的需求基线。需求是质量的起点——理解正确比实现正确更前置（原则三）。

## 质量门禁

进入下一环节（方案设计）前，须满足：

- [ ] 需求经过评审
- [ ] 每条需求有明确的验收标准（Acceptance Criteria）
- [ ] 需求优先级排序完成
- [ ] 需求基线已建立

## 安全要求

- 识别需求中涉及的隐私数据（个人身份信息、学习数据等）
- 标注合规约束（《个人信息保护法》、《数据安全法》、教育行业法规）
- 隐私影响评估（PIA）需求已识别

## 关联原则

- **原则二：领域认知是质量的根基** — 需求定义的过程就是深化领域认知的过程
- **原则三：需求是质量的起点** — 正确的需求理解是后续所有环节的基础
