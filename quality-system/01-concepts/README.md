# 概念层

本目录定义软件质量管理体系的顶层概念，包括质量价值观、质量原则、质量政策、治理规则和例外豁免机制。

概念层是整个质量体系的思想基础，决定后续交付环节、规程动作、流水线验证和质量指标的设计方向。

## 核心定位

质量价值观说明我们相信什么。

质量原则说明我们坚持什么。

质量政策说明组织层面对质量的基本要求。

治理规则说明质量体系如何被执行和维护。

例外与豁免机制说明在特殊情况下如何受控偏离。
