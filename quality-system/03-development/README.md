# 开发构建

## 环节目标

高质量地实现设计意图。开发构建包含单元测试——验证前置，测试是开发的一部分。

## 质量门禁

进入下一环节（质量确认）前，须满足：

- [ ] 代码审查（Code Review）通过
- [ ] 单元测试覆盖率达到目标值（≥ 80%）
- [ ] 静态分析无高危问题
- [ ] CI 构建通过

## 安全要求

- 依赖安全扫描通过
- 安全编码规范遵守
- 无已知高危依赖漏洞

## 关联原则

- **原则一：质量是全团队的责任** — 每位开发者对代码质量负责
- **原则五：验证前置** — 单元测试是开发者的第一道验证
- **原则六：安全是默认属性** — 安全编码从开发阶段开始

## 度量指标

| 指标 | 目标值 |
|------|--------|
| 单元测试覆盖率 | ≥ 80% |
| 代码审查覆盖率 | 100% |
| 静态分析高危问题 | = 0 |
| 构建失败率 | ≤ 5% |
