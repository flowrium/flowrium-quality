# Flowrium Quality

> Flowrium Quality Management System provides a layered and progressive quality assurance framework for modern software engineering. It covers the path from high-level quality principles to executable CI/CD practices to support high-quality software delivery.

**Language**

## Overview

This repository contains a complete software quality management system, including documentation, standards, templates, and automated quality pipeline configuration. The system integrates quality management into each stage of the software lifecycle and promotes built-in quality through standardization and automation.

Key objectives:
- Establish a unified quality standard and shared understanding
- Provide practical and implementable quality assurance engineering practices
- Support compliance with ISO 9001, ISO 27001, and related management system requirements

## Architecture and Directory Guide

The quality system is organized in a modular structure and includes the following core components:

- **[Core Concepts and Governance (01-concepts)](quality-system/01-concepts/)**: Quality values, principles, policies, governance rules, and exception waiver mechanisms.
- **[Delivery Lifecycle Stages (02-delivery-stages)](quality-system/02-delivery-stages/)**: The full software delivery value chain from requirement planning to operational feedback, including detailed procedures for each stage.
- **[Cross-Cutting Domains (03-cross-cutting)](quality-system/03-cross-cutting/)**: Horizontal support areas such as security, configuration management, and requirements traceability that span all delivery stages.
- **[Pipeline Verification Mechanisms (04-pipeline-verification)](quality-system/04-pipeline-verification/)**: Automated quality workflows, CI/CD verification standards, and implementation mechanisms.
- **[AI-Assisted Development Extension (05-ai-coding-extension)](quality-system/05-ai-coding-extension/)**: Quality assurance extensions and best practices for AI-assisted coding tools such as Trae and Copilot.
- **[Metrics and Indicators (06-metrics-reserved)](quality-system/06-metrics-reserved/)**: Quality metrics, dashboards, and evaluation mechanisms.
- **[Standards and Compliance Traceability (07-standard-traceability)](quality-system/07-standard-traceability/)**: Compliance mapping matrices for ISO 9001, ISO 27001, and other relevant standards.
- **[Template Library (templates)](quality-system/templates/)**: Standardized templates required for system implementation.

For detailed architecture, component descriptions, and CI/CD quality workflow examples, see [quality-system/README.md](quality-system/README.md).

## 项目概述

本仓库包含完整的软件质量管理体系，包括文档、规范、模板以及自动化质量流水线配置。该体系将质量管理融入软件生命周期的各个阶段，并通过标准化与自动化推动内建质量。

核心目标：
- 建立统一的质量标准和共同认知
- 提供可落地、可实施的质量保障工程实践
- 支撑 ISO 9001、ISO 27001 及相关管理体系要求的合规工作

## 架构与目录导航

本质量体系采用模块化组织方式，主要包含以下核心组成部分：

- **[核心概念与治理 (01-concepts)](quality-system/01-concepts/)**：质量价值观、原则、方针、治理规则以及例外豁免机制。
- **[交付生命周期阶段 (02-delivery-stages)](quality-system/02-delivery-stages/)**：覆盖从需求规划到运营反馈的完整软件交付价值链，包含各阶段的详细操作规程。
- **[横向贯穿领域 (03-cross-cutting)](quality-system/03-cross-cutting/)**：安全、配置管理、需求追溯等贯穿所有交付阶段的横向支撑领域。
- **[流水线验证机制 (04-pipeline-verification)](quality-system/04-pipeline-verification/)**：自动化质量流程、CI/CD 验证标准及其实现机制。
- **[AI 辅助开发扩展 (05-ai-coding-extension)](quality-system/05-ai-coding-extension/)**：面向 Trae、Copilot 等 AI 辅助编码工具的质量保障扩展与最佳实践。

- **[标准与合规追溯 (07-standard-traceability)](quality-system/07-standard-traceability/)**：面向 ISO 9001、ISO 27001 等标准的合规映射矩阵。
- **[模板库 (templates)](quality-system/templates/)**：体系实施所需的标准化模板。

详细架构、组件说明以及 CI/CD 质量流程示例请参阅 [quality-system/README.md](quality-system/README.md)。
